New command `odoo last-activity [--json]`: shows when the instance last got a real request through the proxy (monitoring, health checks, the open-tab bus, crawlers and scripts are not counted). The proxy keeps the time in `~/.odoo/run/<project>/proxy_exchange/last_activity`; it needs a rebuilt proxy image (`odoo build proxy`, then `odoo up -d`). Until the first such request after that, the command prints `none`.
