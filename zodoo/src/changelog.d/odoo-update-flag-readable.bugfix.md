**Visible change:** during `odoo update` (outside DEVMODE) the bundled proxy shows the maintenance page with HTTP 503 again, and all external requests are blocked for the whole update. This had stopped working in April 2026: the update flag `proxy_exchange/odoo_update` was written with mode 0600, so the proxy's nginx workers (user `nobody`) could not read it. zodoo now writes it with mode 0644.
