Die Panels "CPU usage per container" und "Memory usage per container" im Monitoring-Dashboard waren auf Maschinen mit Docker 29 leer. cadvisor v0.49.1 spricht fest Docker-API 1.41, Docker 29 verlangt mindestens 1.44 -- die Docker-Factory scheiterte beim Start (`client version 1.41 is too old`), cadvisor meldete nur noch den Host (`/`) und keine Container. Der gemeinsame Behaelter `zodoo_cadvisor` laeuft jetzt mit v0.52.1; zodoo erkennt das geaenderte Abbild am Fingerabdruck und legt ihn beim naechsten `odoo up -d` neu an, Odoo selbst wird dabei nicht neu gestartet.

Zum Pruefen: nach `odoo upgrade && odoo up -d` in `docker logs zodoo_cadvisor` nach `Registration of the docker container factory successfully` suchen; unter /system zeigen die beiden Panels nach ein paar Minuten wieder eine Linie pro Container.
