Oben in beiden Monitoring-Dashboards gibt es jetzt eine Link-Leiste "Overview | Logs | Log explorer". Bisher kam man vom Overview (/system) nicht zum Log-Viewer, ohne die Adresse /logs von Hand einzutippen -- das Overview laeuft im Kiosk-Modus, der Grafanas Kopfzeile samt Dashboard-Links ausblendet.

Zum Pruefen: /system oeffnen, oben auf "Logs" klicken -> Log-Viewer; dort auf "Overview" -> zurueck.
