`ODOO_PYTHON_VERSION` accepts Python 3.13 and 3.14 for Odoo 19 and 20. `odoo reload` checks the value against `MIN_PY_VERSION`/`MAX_PY_VERSION` from the project's `odoo/release.py` and aborts with a clear message outside that range. On Python 3.14 the framework requirements install libsass 0.23.0 instead of Odoo's pin 0.22.0, which does not build there.
