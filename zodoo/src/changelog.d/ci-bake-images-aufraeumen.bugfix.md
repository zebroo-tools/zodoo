Nur CI: Der Bake-Test entfernt am Ende die Images seines eigenen Laufs (`bake<lauf>-*`, `zpt19<lauf>-*`, `zptpgbr<lauf>-*`), auch nach einem fehlgeschlagenen oder abgebrochenen Lauf. Vorher blieben die Images jedes Laufs auf dem gemeinsamen Runner liegen, und die Platte lief innerhalb etwa eines Tages voll. Prüfen: In GitHub Actions den Lauf des Workflows „bake-test“ öffnen. Im Schritt „Remove job home“ steht am Ende „removing N images of run …“. Die Warnung „image … stays (still in use?)“ heißt, dass noch ein Container das Image nutzt; es bleibt dann erhalten.
